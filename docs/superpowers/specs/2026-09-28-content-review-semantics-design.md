# 信息内容审核语义优化设计

## 目标

让信息内容审核页面只表达审核职责，并使风险说明与审核记录更易理解。

## 调整

- 将敏感词辅助说明收进标题旁的问号图标，支持鼠标悬浮和键盘聚焦查看。
- 信息内容审核的已处理列表与详情不提供隐藏、恢复等发布管理操作。
- 审核记录只展示内容审核事件，结果明确为“审核通过”或“审核驳回”。
- 每条记录展示审核意见、审核人和审核时间；未填写意见时显示“无补充审核意见”。
- 内容管理模块原有发布管理能力保持不变。

## 验收

- 问号图标可悬浮显示完整辅助说明。
- 已处理审核列表和审核详情均无“隐藏”按钮。
- 审核记录不再使用模糊的“内容审核”标题或重复帖子标题。
