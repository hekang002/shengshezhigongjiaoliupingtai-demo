# 内容审核通过弹窗设计

## 目标

让审核人员在确认操作前快速识别审核对象、触发审核的原因，以及确认后的系统结果，同时减少大面积提示色造成的视觉干扰。

## 信息结构

- 弹窗标题统一为“确认审核通过”。
- “本次审核内容”展示标题、栏目和发布人，使用中性摘要样式。
- 仅在命中规则时展示“敏感词”标签，明确人工审核依据。
- 处理意见保持选填，输入区采用紧凑高度。
- 将业务流向降级为按钮上方的“操作结果”说明，不再使用独立色块。
- 主操作按钮命名为“确认通过”，审核通过后的发布和生成事项逻辑保持不变。

## 视觉与响应式

- 延续现有白色弹窗、红色主操作和方正控件语言。
- 弹窗正文使用清晰的标题、元数据、标签和说明四级层次。
- 736px 宽视口不得产生横向滚动，摘要和结果说明允许自然换行。

## 验收

- 审核对象和敏感词含义无需额外解释即可识别。
- 业务流向呈现为操作结果说明，而非独立功能模块。
- 原有审核提交动作和数据处理不变。
