# 工作总览紧凑顶部设计说明

## 目标

删除重复导航性质的“常用入口”，压缩身份信息与工作指标占用的首屏高度，让平台管理员更快进入“待我处理”和“需关注事项”。

## 信息结构

顶部区域按垂直顺序排列：

1. 紧凑身份条：头像、姓名、角色、所属工作组、授权数据范围。
2. 四项工作指标：待我处理、处理中事项、长时间未回复、已回复事项。
3. 待我处理任务队列。
4. 需关注事项。

删除身份卡中的“常用入口”和“查看驾驶舱”。页面导航继续由左侧主导航承担，避免同一入口重复出现。

## 视觉规则

- 身份信息使用单行横向条，头像缩小，数据范围靠右显示。
- 四项指标使用等宽横排，不再使用两行两列的大卡布局。
- 指标之间只使用细分隔线和左侧状态色，避免多个独立浮动卡片。
- “长时间未回复”使用浅琥珀背景、琥珀色数字和“需关注”标记。
- “待我处理”保留红色强调；“处理中事项”使用金色；“已回复事项”使用绿色。
- 所有统计口径信息图标和点击行为保持不变。

## 响应规则

工作台继续作为桌面管理界面，保持最小画布宽度 `980px`。窄浏览器面板允许整体横向滚动，但身份条、指标标签和数字不得相互遮挡或换行错位。

## 验收标准

- 页面不再出现“常用入口”或“查看驾驶舱”。
- 身份条只占一行，授权范围清晰可见。
- 四项指标在同一行等宽排列。
- “长时间未回复”有克制的琥珀色关注状态，不使用危险红色。
- 顶部整体高度明显低于当前版本，“待我处理”在首屏中上移。
- 统计数值、口径提示和点击行为保持不变。
