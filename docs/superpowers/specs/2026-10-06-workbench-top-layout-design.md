# 工作台顶部布局调整设计说明

## 目标

按用户标注重组运营工作台首屏，使“身份与入口”和“当前待办”形成明确的左右关系。

## 已确认布局

- 将“常用入口”移入身份卡，放在“数据范围”下方。
- 将“当前待办总数、已回复事项、专题办理、公开内容”四项整体放到身份卡右侧。
- 右侧统计组采用 2×2 排列，保持字号、说明和点击区域的可读性。
- “我的工作队列”和“事项处理进度”保持不变。

## 交互与口径

- 当前待办总数继续使用现有算法：待审核 + 待处理 + 待公开。
- 信息图标继续支持鼠标悬浮和键盘聚焦查看统计口径。
- 常用入口按钮保留原导航行为。

## 验收标准

- 常用入口在身份卡内，且位于数据范围下方。
- 四项统计位于身份卡右侧，统计组与身份卡高度对齐。
- 顶部下方直接进入“我的工作队列”，不再保留独立的结果指标行。
- 页面不再出现独立的常用入口卡片。
