# 信息内容审核表格字段调整设计

## 目标

让信息内容审核表格的字段与当前业务阶段匹配，避免在事项尚未生成时展示“办理状态”造成误解。

## 设计

- “待审核”和“风险待审”列表不展示“办理状态”或“通过后处理”，处理结果由审核成功后的界面反馈告知用户。
- “已处理”列表保留状态列，列名明确为“事项状态”，用于核对是否已生成关联事项。
- 审核详情将系统检测结论与命中敏感词合并为一个“敏感词检测”区块。标题右侧用紧凑标签展示风险等级和“需人工确认”，下方逐个展示实际命中词。个人信息和保护名单作为额外风险标记。
- 详情正文标题区只展示内容分类，不重复展示“未发布”；敏感词检测区只展示风险等级，不再展示“需人工确认”。
- 审核记录从左侧正文区移至右侧信息栏，位于发布信息之后；左侧仅保留原文与附件。
- “发布与办理信息”简化为“发布信息”，仅保留发布方式、审核状态和发布状态。
- 审核详情删除“审核通过后的流向”。
- 不改变审核、发布和事项生成的数据逻辑。

## 验收标准

- 三个审核队列的表头与行数据一一对应。
- 待审核与风险待审不再出现“办理状态”和“通过后处理”。
- 已处理显示“事项状态”。
- 详情页只使用一个区块展示风险等级、人工确认要求和具体命中词，不展示重复的检测结论、办理与流向信息。
- 窄屏下表格可横向滚动，不造成页面级水平溢出。
